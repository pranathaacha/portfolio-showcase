# Ceracon Desktop

Offline-first showroom software

A quote, a reservation, and a dispatch each mean something different to the person counting boxes.

## My work

I mapped the showroom workflow with the owner and built a Windows application around physical, reserved, and available stock. Separate delivery trips, returns, billing, and payments follow the same order. Try the sample inventory below.
