# Teamstead

Independent employee workspace

A small business needs a place for the questions, requests, and updates that happen between meetings.

## My work

I built an independent workspace with Microsoft sign-in, a staff directory, announcements, requests, and onboarding checklists. The staging deployment uses a private database and an Azure Functions API.
