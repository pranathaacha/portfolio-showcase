# Formula 1: the sponsorship shortlist

University of the Pacific

Which drivers would make a compelling sponsorship bet for PepsiCo?

## My work

I organized race and driver data in SQL Server, scored performance and brand alignment, and presented a shortlist through Tableau. The recommendation explains the tradeoff between visibility, performance, and strategic fit.

## Tools and methods

SQL Server · T-SQL · Tableau
